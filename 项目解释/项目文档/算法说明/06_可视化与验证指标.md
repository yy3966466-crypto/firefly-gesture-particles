# 可视化与验证指标

对应源码：

- `src/BioMonitorApp.m`
- `src/+bioout/exportAnalysisReport.m`
- `src/+bioalg/estimateSnr.m`

## 1. 可视化目标

可视化用于证明算法确实完成了“预处理、特征提取、参数计算和异常提示”。项目提供两类可视化：

- 主 GUI 实时可视化；
- 离线导出分析图和 CSV 表格。

## 2. 主 GUI 实时可视化

主界面实时显示：

| 区域 | 显示内容 |
| --- | --- |
| ECG 曲线 | 滤波后 ECG 和 R 波散点 |
| 呼吸曲线 | 增强后呼吸信号和呼吸峰散点 |
| 体温曲线 | demo 或串口体温时间序列 |
| 参数面板 | 心率、呼吸率、体温 |
| 报警框 | 阈值报警和节律异常提示 |
| 分析框 | SNR、累计峰值、心呼相关、体温趋势 |

## 3. GUI 绘图优化

为了降低卡顿，当前实现采用：

- 曲线刷新周期 `0.50 s`；
- 参数刷新周期 `1.00 s`；
- 分析刷新周期 `2.00 s`；
- `drawnow limitrate nocallbacks` 限制 UI 回调和刷新频率；
- `localThinIndexVector` 将显示点数限制在 `MaxPlotPoints = 1500` 以内。

## 6. 验证指标

当前项目实现的量化指标：

| 指标 | 来源 | 作用 |
| --- | --- | --- |
| SNR | `estimateSnr.m` | 粗略评价处理后信号相对残差的能量 |
| R 波数量 | ECG 检测结果 | 评价 ECG 检测覆盖情况 |
| 呼吸峰数量 | 呼吸检测结果 | 评价呼吸峰检测覆盖情况 |
| 平均 HR/RR | 峰间隔计算 | 评价关键生理参数 |
| HR/RR 标准差 | 统计计算 | 评价波动程度 |
| RR 间期 CV | 心律异常提示 | 判断心律稳定性 |
| 呼吸周期 CV | 呼吸异常提示 | 判断呼吸节律稳定性 |
| 心呼相关系数 | HR/RR 插值后相关 | 初步融合分析 |
| 体温趋势斜率 | 最近 30 秒线性拟合 | 判断升温、降温或稳定 |

## 7. SNR 估计方法

对应源码：`src/+bioalg/estimateSnr.m`

```matlab
residual = rawSignal - cleanedSignal;
signalPower = mean(cleanedSignal .^ 2, 'omitnan');
noisePower = mean(residual .^ 2, 'omitnan');
snrDb = 10 * log10((signalPower + eps) / (noisePower + eps));
```

说明：

- `cleanedSignal` 作为处理后有效信号估计；
- `raw-cleaned` 作为残差估计；
- 该指标适合项目内部相对比较，不等同于有真实噪声标注时的严格 SNR。

## 8. 代表窗口选择

导出图不是使用完整长记录，而是选择代表窗口：

- ECG 默认窗口约 10 秒；
- 呼吸默认窗口约 30 秒；
- 优先选择心率/呼吸率偏离中位数较明显的位置；
- 若没有速率数据，则选择信号中间位置。

这样导出的图更容易展示异常、峰值检测和算法效果。
