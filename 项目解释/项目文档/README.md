# 项目文档索引

本文件夹用于集中整理“通用型多生理参数监护系统”的运行说明、项目介绍、界面说明、数据输出说明和算法说明。所有文档均对应当前项目源码，不需要修改 MATLAB 全局路径或项目外文件。

## 文档结构

- `01_项目介绍.md`：说明项目目标、系统组成、数据来源、目录结构和功能模块。
- `02_运行程序说明.md`：说明 MATLAB 运行环境、启动命令、主界面运行流程、体温传感器单独 UI 使用方法、常见问题处理。
- `03_界面与输出说明.md`：说明 GUI 控件、实时显示区域、保存会话、导出分析图和输出文件含义。
- `算法说明/`：单独的算法文档子文件夹，详细说明 ECG、呼吸、体温、融合报警和可视化导出算法。

## 推荐阅读顺序

1. 先读 `01_项目介绍.md`，了解系统整体功能。
2. 再读 `02_运行程序说明.md`，按步骤启动主程序或体温传感器小界面。
3. 需要写报告、答辩或解释实现原理时，阅读 `算法说明/README.md` 和对应算法文件。
4. 需要导出论文/汇报图时，阅读 `03_界面与输出说明.md` 中的导出说明。

## 主要入口

| 入口文件 | 作用 |
| --- | --- |
| `main.m` | 启动综合监护 GUI 主程序 |
| `temperature_sensor_ui.m` | 启动 Type-C 体温传感器独立读取界面 |
| `smoke_test.m` | 验证数据下载、解析、算法和 demo 体温通道 |
| `export_analysis_report.m` | 导出 ECG/呼吸处理前后对比图、检测图和 CSV 数据 |

## 重要说明

- 当前体温传感器按体温模式默认读取，命令为 `0xAB`。
- 体温显示值按传感器返回帧直接解析，例如 `+000365` 显示为 `36.5 °C`。
- 报警逻辑只在界面显示报警信息，不触发蜂鸣声，避免 UI 卡顿。
- 项目运行时通过 `main.m` 或 `temperature_sensor_ui.m` 将 `src` 临时加入当前 MATLAB 会话路径，不会修改 MATLAB 全局路径。
