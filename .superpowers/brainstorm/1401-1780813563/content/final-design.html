设计总览 · 萤火虫手势粒子交互

Three.js + MediaPipe Hands · 浏览器端 · 支持移动端

项目结构

firefly-particles/
├── index.html           主页面 + 全屏 Canvas
├── style.css            布局 + 加载提示
├── src/
│   ├── main.js          入口：初始化，主循环 requestAnimationFrame
│   ├── camera.js         getUserMedia，视频纹理贴到背景面片
│   ├── hand-detector.js   MediaPipe Hands 加载 + 关键点提取
│   ├── gesture-classifier.js 关键点 → 手势分类（状态机）
│   ├── particle-engine.js  Three.js 粒子系统 + 自定义 Shader
│   ├── physics.js        波浪/涟漪/爆炸/光环四种力学生成器
│   ├── audio.js          Web Audio API 流水/微风/叮咚音效
│   └── utils.js          数学工具、缓动函数、移动端检测
└── shaders/
    ├── firefly.vert      粒子顶点着色器
    └── firefly.frag      粒子片元着色器（径向渐变发光）

关键依赖

Three.js CDN 引入，~140KB gzip 3D 渲染 + 粒子 Shader
@mediapipe/hands CDN，~4MB（WASM 模型） 21 关键点手部追踪
Web Audio API 浏览器原生，零依赖 流水/微风/叮咚音效合成

已确认的设计决策

  • Three.js + MediaPipe Hands 技术栈
  • 萤火虫黄绿暖光 + 暗蓝紫夜空背景
  • 镜像 AR 模式（摄像头背景 + 粒子叠加）
  • 3 手势：涟漪/炸开恢复/光环轨迹
  • 真实物理推动（粒子受力移动）
  • 自然音效：流水 + 微风 + 叮咚
  • 桌面 300 粒子，移动端 180 粒子
