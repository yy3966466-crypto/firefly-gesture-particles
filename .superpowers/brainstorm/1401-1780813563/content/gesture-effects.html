手势 → 粒子效果映射方案

基于 MediaPipe 可识别的手势，推荐三组风格不同的搭配

方案 A · 元素操控风

手势像操控元素一样，简单直觉

A

元素操控风

✋ 张开手掌 → 粒子从掌心向外辐射扩散

✊ 握拳 → 粒子迅速聚拢收缩成球

👆 食指指向 → 指尖射出一束粒子流

🤏 捏合 → 粒子被"捏住"静止，松手弹开

👋 挥动 → 粒子跟随手运动方向产生拖尾

方案 B · 情绪仪式风

每只手势像施法一样，仪式感强

B

情绪仪式风

✋ 五指张开 → 全场粒子"绽放"为彩色烟花

✊ 握拳 → 粒子瞬间坍缩为奇点，再慢慢释放

✌️ 剪刀手 → 粒子分成两股绕手指旋转

👍 竖拇指 → 粒子从底部向上喷涌（像点赞气泡）

👏 双手合十 → 全场粒子汇聚成光柱冲天

方案 C · 极简流动风

手势少而精，重点是默认流动状态的观赏性

C

极简流动风

🌊 默认：粒子呈波浪流体持续流动

✋ 张开手掌 → 粒子形成漩涡，手掌位置为漩涡中心

✊ 握拳 → 粒子瞬间爆炸四散，然后缓缓恢复波浪流动

👆 食指画圈 → 粒子随指尖画出光环轨迹

（只保留 3 个核心手势，降低学习成本）

方案 A 偏向交互性，B 偏向表演性，C 偏向观赏性。看看哪个方向更接近你想要的感觉？
