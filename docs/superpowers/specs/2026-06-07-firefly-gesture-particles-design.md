# 萤火虫手势粒子交互 · 设计文档

## 概述

基于浏览器的实时手势粒子交互应用。摄像头捕捉手部动作，Three.js 渲染萤火虫风格粒子，粒子默认呈水波纹波浪流动，特定手势触发涟漪扩散、炸开恢复、光环轨迹等动画效果。支持桌面和移动端。

## 技术选型

- **Three.js**：WebGL 粒子渲染 + 自定义 Shader（CDN 引入，~140KB gzip）
- **@mediapipe/hands**：手部 21 关键点追踪（CDN，WASM 模型 ~4MB）
- **Web Audio API**：音效合成（浏览器原生，零依赖）
- **getUserMedia**：摄像头画面获取

方案考量：Canvas 2D 光效表现力不足，PixiJS 自定义 Shader 灵活性不如 Three.js。Three.js 的 PointsMaterial + 自定义 Shader 能以最少代码实现最佳视觉效果，且粒子系统生态成熟。

## 架构

```

│  摄像头层  getUserMedia + video  │
├─────────────────────────────────┤

├─────────────────────────────────┤
│  手势分类  状态机 + 阈值判断      │
├─────────────────────────────────┤
│  粒子引擎  Three.js + Shader     │
│  ├ 波浪流动（默认）              │
│  ├ 涟漪扩散（✋ 触发）           │
│  ├ 炸开恢复（✊ 触发）           │
│  └ 光环轨迹（👆 触发）           │
├─────────────────────────────────┤
│  音效层    Web Audio API         │

```

数据流：摄像头帧 → MediaPipe 21 关键点 → 手势分类器（状态机）→ 粒子引擎（位置/速度/力）→ Three.js 渲染 → 合成输出

## 手势定义

| 手势 | 判断逻辑 | 粒子响应 |
|------|---------|---------|
| ✋ 张开手掌 | 五指指尖间距 > 阈值 | 以手掌为中心发出径向排斥力，推动粒子；发出 3~4 道涟漪圆环 |
| ✊ 握拳 | 五指指尖间距 < 阈值 | 阶段一：粒子被引力拉向拳心（~300ms）；阶段二：径向炸开（v=200~600 px/s）；~2s 内阻尼回归波浪 |
| 👆 食指画圈 | 食指轨迹累积角度 > 300° | 沿途粒子吸附到轨迹形成光环，保持 ~3s 后散开 |

## 粒子物理

### 默认波浪流动
- 每粒子独立正弦运动：`x(t)=x0+Ax·sin(ωt+φx)`, `y(t)=y0+Ay·cos(ωt+φy)`
- 振幅 20~60px 随机，频率 0.5~1.5 Hz，相位随机

### 涟漪力场（✋）
- 径向排斥力：`F=k/r²`（r 为粒子到手心距离，k≈800~1500）
- 作用半径 ~200~300px，超出无力
- 粒子被推出力场后减速回归波浪
- 视觉涟漪圆环持续 ~1.5s

### 炸开恢复（✊）
- 引力阶段：粒子向拳心聚合
- 爆炸：随机径向速度 200~600 px/s
- 恢复：阻尼系数 0.95，约 2s 回归波浪
- 聚合时变亮，爆炸瞬间白光闪烁

### 光环轨迹（👆）
- 食指运动轨迹累积角度 > 300° 触发
- 沿途粒子吸附到轨迹，形成发光环
- 光环粒子亮度+尺寸增大
- 保持 ~3s 后粒子散开

## 音效设计

- **底噪**：柔和流水声（白噪声 + 低通滤波 + LFO 调制模拟水波）
- **微风**：粉红噪声 + 高通滤波，低音量持续
- **涟漪触发**：清脆叮咚音（正弦波 + 快速衰减包络，频率 ~800Hz）
- **爆炸触发**：低频嗡 + 高频碎散音（噪声爆发 + 短衰减）
- **光环触发**：持续上升音阶（3~4 个递增频率的叮咚串联）

## 界面

- 全屏 Canvas，无可见 UI 控件
- 首次加载：屏幕中央淡入文字引导「试试张开手掌 ✨」，3 秒后淡出
- 角落（右下）：小型手势状态指示器
  - 灰色圆点：等待摄像头/未检测到手
  - 绿色圆点 + 手势名：识别到手势
- 加载中：中央 spinner + 「正在加载手势模型...」

## 文件结构

```
firefly-particles/
├── index.html          # 主页面 + 全屏 Canvas 容器
├── style.css           # 布局 + 加载/引导动画
├── src/
│   ├── main.js         # 入口，初始化各模块，requestAnimationFrame 主循环
│   ├── camera.js       # getUserMedia，视频纹理贴 Three.js 背景面片
│   ├── hand-detector.js    # MediaPipe Hands 加载 + 21 关键点提取
│   ├── gesture-classifier.js # 关键点 → 手势分类（状态机）
│   ├── particle-engine.js   # Three.js 粒子系统 + BufferGeometry + ShaderMaterial
│   ├── physics.js      # 波浪/涟漪/爆炸/光环四种力学生成器
│   ├── audio.js        # Web Audio API 音效合成
│   └── utils.js        # 数学工具、缓动函数、移动端检测
└── shaders/
    ├── firefly.vert    # 顶点着色器
    └── firefly.frag    # 片元着色器（径向渐变发光）
```
